# MINST TRAIN: Week 1-7

This repository contains the `MINST TRAIN` learning project, covering seven weeks of handwritten digit recognition practice using the Digits/MNIST dataset. Each week includes a focused task that builds from data exploration to model training, evaluation, and workflow improvement.

---

## 🎯 Project Overview

`MINST TRAIN` is a step-by-step AI practice portfolio with the following goals:
- Understand digit image data
- Train and evaluate classification models
- Improve results through iteration
- Organize code into reusable workflows

The folder demonstrates a progression from single-file experiments to more structured project layouts.

---

## 📅 Weekly Breakdown

### Week 1: Data Exploration
**Focus:** Load and inspect the dataset
- View digit images
- Analyze class balance
- Understand dataset shape and labels

**Key File:** `MINST TRAIN/week 1/week 1 task.py`

### Week 2: Basic Model Training
**Focus:** Train initial models and compare variants
- Train basic classifiers
- Evaluate model accuracy
- Improve task versions iteratively

**Key Files:**
- `MINST TRAIN/week 2/week 2 original task.py`
- `MINST TRAIN/week 2/extention.py`
- `MINST TRAIN/week 2/week 2 task change 1.py`
- `MINST TRAIN/week 2/week 2 task change 2.py`

### Week 3: Continued Improvements
**Focus:** Refine training and analysis
- Test updated model versions
- Study how changes affect results

**Key Files:**
- `MINST TRAIN/week 3/week 3 original task.py`
- `MINST TRAIN/week 3/week 3 task change 1.py`

### Week 4: Task Consolidation
**Focus:** Finalize the fourth-week model task
- Complete the core week 4 experiment

**Key File:** `MINST TRAIN/week 4/week 4 task.py`

### Week 5: Structured Practice
**Focus:** Use a modular project layout
- Separate main logic and helper code
- Build a clearer workflow

**Key Folder:** `MINST TRAIN/week 5/week 5 task/`

### Week 6: Modular Training Pipeline
**Focus:** Improve code organization
- Keep training and evaluation code reusable
- Continue modular design

**Key Folder:** `MINST TRAIN/week 6/week 6 original task/`

### Week 7: Model Comparison
**Focus:** Compare performance across models
- Evaluate different algorithms
- Analyze accuracy and confusion behavior

**Key Folder:** `MINST TRAIN/week 7/week 7 original task/`
